# 3. Elemento Majoritario

## Enunciado

Dado um vetor com `n` inteiros, encontre um elemento que aparece mais que
`n / 2` vezes. Se nao existir, imprima `-1`.

Resolva usando divisao e conquista.

## Entrada

```text
n
a1 a2 ... an
```

## Saida

```text
elemento_majoritario_ou_-1
```

## Exemplo

Entrada:

```text
7
2 2 1 2 3 2 2
```

Saida:

```text
2
```
