# 5. Subarray Maximo por Divisao e Conquista

## Enunciado

Dado um vetor com `n` inteiros, encontre a maior soma de um subarray continuo
nao vazio.

Resolva usando divisao e conquista.

## Entrada

```text
n
a1 a2 ... an
```

## Saida

```text
maior_soma
```

## Exemplo

Entrada:

```text
8
-2 -3 4 -1 -2 1 5 -3
```

Saida:

```text
7
```
