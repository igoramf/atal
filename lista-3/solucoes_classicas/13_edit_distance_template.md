# Distancia de Edicao

## Enunciado

Dadas duas strings `a` e `b`, calcule o menor numero de operacoes necessario
para transformar `a` em `b`.

Operacoes permitidas:

```text
inserir um caractere
remover um caractere
trocar um caractere
```

## Entrada

```text
a
b
```

## Saida

Imprima a distancia de edicao.

## Exemplo

Entrada:

```text
kitten
sitting
```

Saida:

```text
3
```
