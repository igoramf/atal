# Mochila 0/1

## Enunciado

Dado `n` itens, cada um com peso e valor, e uma mochila de capacidade `W`,
determine o maior valor possivel sem ultrapassar a capacidade.

Cada item pode ser escolhido no maximo uma vez.

## Entrada

```text
n W
peso1 valor1
peso2 valor2
...
peson valorn
```

## Saida

Imprima o maior valor possivel.

## Exemplo

Entrada:

```text
3 5
2 3
3 4
4 5
```

Saida:

```text
7
```
