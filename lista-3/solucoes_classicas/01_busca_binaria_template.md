# Busca Binaria

## Enunciado

Dado um vetor ordenado com `n` inteiros e `q` consultas, encontre a posicao de
cada valor consultado. Se o valor nao estiver no vetor, imprima `-1`.

## Entrada

```text
n q
a1 a2 ... an
x1
x2
...
xq
```

## Saida

Para cada consulta, imprima a posicao `0-indexada` do valor ou `-1`.

## Exemplo

Entrada:

```text
5 3
1 3 5 7 9
5
2
9
```

Saida:

```text
2
-1
4
```
