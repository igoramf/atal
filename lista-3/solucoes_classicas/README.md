## Como usar na prova

```text
1. Abra o .md para conferir o enunciado e o formato da entrada.
2. Copie o .py mais parecido.
3. Ajuste a leitura da entrada.
4. Ajuste o que precisa imprimir.
5. Teste com o exemplo do enunciado.
```

Se estiver em duvida entre dois moldes:

```text
itens com capacidade -> mochila
soma alvo sim/nao -> subset sum
menor quantidade para formar valor -> troco minimo
quantas formas de formar valor -> troco numero de formas
duas strings -> LCS ou edit distance
subsequencia crescente em uma lista -> LIS
menor caminho entre todos os pares -> Floyd-Warshall
```
