# Quickselect

## Enunciado

Dado um vetor com `n` inteiros e um indice `k`, encontre o elemento que ficaria
na posicao `k` se o vetor estivesse ordenado.

Use `k` como indice `0-indexado`.

## Entrada

```text
n k
a1 a2 ... an
```

## Saida

Imprima o `k`-esimo menor elemento.

## Exemplo

Entrada:

```text
5 2
4 1 5 2 3
```

Saida:

```text
3
```
