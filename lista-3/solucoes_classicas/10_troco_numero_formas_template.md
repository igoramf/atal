# Numero de Formas de Fazer Troco

## Enunciado

Dado um conjunto de moedas e um valor alvo `S`, conte de quantas formas
diferentes e possivel formar `S`.

Cada moeda pode ser usada quantas vezes quiser. A ordem das moedas nao importa.

## Entrada

```text
n S
c1 c2 ... cn
```

## Saida

Imprima a quantidade de formas.

## Exemplo

Entrada:

```text
3 5
1 2 5
```

Saida:

```text
4
```
