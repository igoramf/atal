# Caminhos em Grade

## Enunciado

Dada uma grade `n x m`, conte quantos caminhos existem do canto superior
esquerdo ate o canto inferior direito.

Voce so pode andar para baixo ou para a direita. Celulas com `#` sao bloqueadas
e celulas com `.` sao livres.

## Entrada

```text
n m
linha1
linha2
...
linhan
```

## Saida

Imprima a quantidade de caminhos.

## Exemplo

Entrada:

```text
3 3
...
.#.
...
```

Saida:

```text
2
```
