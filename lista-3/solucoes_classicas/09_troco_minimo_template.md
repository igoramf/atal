# Troco Minimo

## Enunciado

Dado um conjunto de moedas e um valor alvo `S`, encontre o menor numero de
moedas necessario para formar exatamente `S`.

Cada moeda pode ser usada quantas vezes quiser.

## Entrada

```text
n S
c1 c2 ... cn
```

## Saida

Imprima o menor numero de moedas ou `-1` se for impossivel.

## Exemplo

Entrada:

```text
3 11
1 5 7
```

Saida:

```text
3
```
