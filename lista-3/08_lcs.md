# 8. Maior Subsequencia Comum

## Enunciado

Dadas duas strings `a` e `b`, calcule o tamanho da maior subsequencia comum
entre elas.

Subsequencia nao precisa ser continua, mas deve manter a ordem.

## Entrada

```text
a
b
```

## Saida

```text
tamanho_da_lcs
```

## Exemplo

Entrada:

```text
ABCBDAB
BDCABA
```

Saida:

```text
4
```
