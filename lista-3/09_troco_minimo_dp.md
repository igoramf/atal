# 9. Troco Minimo com Programacao Dinamica

## Enunciado

Dado um conjunto de moedas e um valor `S`, determine o menor numero de moedas
necessario para formar exatamente `S`.

Voce pode usar cada moeda quantas vezes quiser.

Se nao for possivel formar `S`, imprima `-1`.

## Entrada

```text
n S
c1 c2 ... cn
```

## Saida

```text
menor_numero_de_moedas_ou_-1
```

## Exemplo

Entrada:

```text
3 11
1 5 7
```

Saida:

```text
3
```
