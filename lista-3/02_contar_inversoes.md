# 2. Contar Inversoes

## Enunciado

Dado um vetor com `n` inteiros, conte quantos pares `(i, j)` existem tais que:

```text
i < j
a[i] > a[j]
```

Resolva usando a ideia do merge sort.

## Entrada

```text
n
a1 a2 ... an
```

## Saida

```text
quantidade_de_inversoes
```

## Exemplo

Entrada:

```text
5
2 4 1 3 5
```

Saida:

```text
3
```
