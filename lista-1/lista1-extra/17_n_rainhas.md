# 17. N-Rainhas

## Enunciado

Dado um tabuleiro `n x n`, conte de quantas formas e possivel posicionar `n`
rainhas sem que uma ataque a outra.

Duas rainhas se atacam se estiverem na mesma linha, na mesma coluna ou na
mesma diagonal.

## Entrada

A entrada contem um unico inteiro:

```text
n
```

## Saida

Imprima um unico inteiro: a quantidade de configuracoes validas.

## Restricoes

```text
1 <= n <= 10
```

## Exemplo

Entrada:

```text
4
```

Saida:

```text
2
```
