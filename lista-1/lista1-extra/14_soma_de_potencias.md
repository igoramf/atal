# 14. Soma de Potencias

## Enunciado

Dado um inteiro `x` e uma potencia `n`, conte de quantas formas diferentes `x`
pode ser escrito como soma de potencias `n`-esimas de numeros naturais
distintos.

Cada base pode ser usada no maximo uma vez.

## Entrada

A primeira linha contem o inteiro `x`.

A segunda linha contem o inteiro `n`.

## Saida

Imprima um unico inteiro: a quantidade de formas diferentes.

## Restricoes

```text
1 <= x <= 1000
2 <= n <= 10
```

## Exemplo

Entrada:

```text
10
2
```

Saida:

```text
1
```

Explicacao:

```text
10 = 1^2 + 3^2
```
