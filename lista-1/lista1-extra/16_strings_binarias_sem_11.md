# 16. Strings Binarias sem 11

## Enunciado

Dado um inteiro `n`, gere todas as strings binarias de tamanho `n` que nao
possuem dois caracteres `1` consecutivos.

As strings devem ser impressas em ordem lexicografica.

## Entrada

A entrada contem um unico inteiro:

```text
n
```

## Saida

Na primeira linha, imprima a quantidade de strings validas.

Nas linhas seguintes, imprima uma string valida por linha, em ordem
lexicografica.

## Restricoes

```text
1 <= n <= 20
```

## Exemplo

Entrada:

```text
3
```

Saida:

```text
5
000
001
010
100
101
```
