# 6. Caminho em Grade com 4 Direcoes

## Enunciado

Dada uma matriz com celulas livres `.`, bloqueadas `#`, inicio `S` e fim `E`,
descubra se existe pelo menos um caminho de `S` ate `E`.

Voce pode se mover para cima, baixo, esquerda e direita.

## Entrada

A primeira linha contem dois inteiros:

```text
n m
```

As proximas `n` linhas contem a matriz.

## Saida

Imprima `YES` se existir caminho de `S` ate `E`. Caso contrario, imprima `NO`.

## Exemplo

Entrada:

```text
3 3
S..
##.
..E
```

Saida:

```text
YES
```
