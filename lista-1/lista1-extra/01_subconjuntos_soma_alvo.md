# 1. Subconjuntos com Soma Alvo

## Enunciado

Dado um array com `n` inteiros positivos e um valor alvo `S`, conte quantos
subconjuntos possuem soma exatamente igual a `S`.

Cada elemento pode ser escolhido no maximo uma vez.

## Entrada

A primeira linha contem dois inteiros:

```text
n S
```

A segunda linha contem `n` inteiros:

```text
v1 v2 ... vn
```

## Saida

Imprima um unico inteiro: a quantidade de subconjuntos cuja soma e exatamente
`S`.

## Restricoes

```text
1 <= n <= 20
1 <= vi <= 100
1 <= S <= 1000
```

## Exemplo

Entrada:

```text
4 5
1 2 3 4
```

Saida:

```text
2
```
