# 3. Permutacoes sem Repeticao

## Enunciado

Dada uma string com caracteres distintos, imprima todas as permutacoes possiveis
dos seus caracteres.

## Entrada

A entrada contem uma unica string `s`.

## Saida

Imprima todas as permutacoes de `s`, uma por linha.

## Exemplo

Entrada:

```text
abc
```

Saida:

```text
abc
acb
bac
bca
cab
cba
```
