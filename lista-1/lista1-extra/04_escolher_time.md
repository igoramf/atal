# 4. Escolher Time

## Enunciado

Voce tem `n` jogadores. Cada jogador possui uma habilidade `hi`.

Escolha exatamente `k` jogadores de forma que a soma das habilidades escolhidas
seja a maior possivel.

## Entrada

A primeira linha contem dois inteiros:

```text
n k
```

A segunda linha contem `n` inteiros:

```text
h1 h2 ... hn
```

## Saida

Imprima um unico inteiro: a maior soma de habilidades possivel escolhendo
exatamente `k` jogadores.

## Exemplo

Entrada:

```text
5 3
4 10 2 8 6
```

Saida:

```text
24
```
