# 8. Expressoes com + e -

## Enunciado

Dado um array de numeros e um alvo `T`, coloque `+` ou `-` antes de cada numero
para que o resultado final seja `T`.

Conte quantas formas diferentes existem.

## Entrada

A primeira linha contem dois inteiros:

```text
n T
```

A segunda linha contem `n` inteiros:

```text
v1 v2 ... vn
```

## Saida

Imprima um unico inteiro: a quantidade de formas de obter o alvo.

## Exemplo

Entrada:

```text
3 2
1 2 3
```

Saida:

```text
1
```
