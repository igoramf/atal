# 13. Criando Strings

## Enunciado

Dada uma string, gere todas as strings diferentes que podem ser formadas
reordenando seus caracteres.

As strings devem ser impressas em ordem lexicografica.

## Entrada

A entrada contem uma unica string:

```text
s
```

## Saida

Na primeira linha, imprima a quantidade de strings diferentes.

Nas linhas seguintes, imprima uma string por linha, em ordem lexicografica.

## Restricoes

```text
1 <= len(s) <= 8
s contem apenas letras minusculas de 'a' ate 'z'
```

## Exemplo

Entrada:

```text
aab
```

Saida:

```text
3
aab
aba
baa
```
