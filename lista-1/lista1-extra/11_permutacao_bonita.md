# 11. Permutacao Bonita

## Enunciado

Dado um inteiro `n`, construa uma permutacao dos numeros de `1` ate `n` em
que nenhum par de elementos adjacentes tenha diferenca igual a `1`.

Se nao existir uma permutacao valida, imprima `NO SOLUTION`.

## Entrada

A entrada contem um unico inteiro:

```text
n
```

## Saida

Imprima uma permutacao valida dos numeros de `1` ate `n`, ou `NO SOLUTION`
caso ela nao exista.

## Restricoes

```text
1 <= n <= 10^6
```

## Exemplo 1

Entrada:

```text
5
```

Saida:

```text
2 4 1 3 5
```

## Exemplo 2

Entrada:

```text
3
```

Saida:

```text
NO SOLUTION
```
