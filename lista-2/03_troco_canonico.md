# 3. Troco Canonico

Dado um valor `v`, determine o menor numero de moedas necessario para formar esse valor usando moedas de valores:

```text
1, 5, 10, 25, 50
```

Voce pode usar quantas moedas quiser de cada tipo.

## Entrada

```text
v
```

## Saida

```text
menor quantidade de moedas
```

## Exemplo

```text
Entrada:
87

Saida:
5
```

Explicacao: `50 + 25 + 10 + 1 + 1`.

## Classificacao

Guloso.
