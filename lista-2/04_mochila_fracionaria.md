# 4. Mochila Fracionaria

Voce tem `n` itens. Cada item tem peso `w[i]` e valor `v[i]`. Sua mochila suporta no maximo peso `W`.

Voce pode pegar qualquer fracao de um item. Determine o maior valor total possivel dentro da mochila.

## Entrada

```text
n W
w1 v1
w2 v2
...
wn vn
```

## Saida

```text
maior valor possivel
```

## Exemplo

```text
Entrada:
3 50
10 60
20 100
30 120

Saida:
240
```

## Classificacao

Guloso.
